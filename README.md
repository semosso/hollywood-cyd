# hollywood-cyd

Simulador de carreira em Hollywood no formato "choose your destiny": run curta, escolhas às cegas
entre filmes e pessoas reais, revelação depois da escolha, card final compartilhável.

- **Jogar**: https://thank-the-academy.vnazambuja.workers.dev/ (Cloudflare, build a cada push) · espelho: https://semosso.github.io/hollywood-cyd/ (GitHub Pages)
- Documento de design e brainstorm: [`docs/BRAINSTORM.md`](docs/BRAINSTORM.md) · regras do motor: [`docs/RULES.md`](docs/RULES.md)
- Referências de formato: 82-0, 7-0, Copero (simulador de carrera), Volante de Ouro
- Dados: TMDB (filmes, elenco, bilheteria), OMDb (crítica), prêmios via Wikidata/dataset público

Fan-made. Sátira. Não afiliado a nenhum estúdio, pessoa ou premiação.
